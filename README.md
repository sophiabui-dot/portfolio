# Sophia Bui Portfolio

A simple, responsive graphic design portfolio inspired by the supplied
wireframe. Open `index.html` in a browser to view it; no build tools or
dependencies are required.

The full-color project thumbnails gently drift away from the cursor and move to
the front on hover or keyboard focus. Each thumbnail links to its own page in
`projects/`. To personalize the site, update the images, project details, about
dialog, and contact email in `index.html` and the corresponding project pages.
Project photography loads from Unsplash.

The homepage also includes an animated sparkle cursor and an original,
procedurally generated ambient loop. A music toggle is fixed to the bottom-right
corner; when the browser blocks autoplay, select **Play music** to start audio.

The visual theme follows Sophia's personal logo: crisp white, black, bright
red, sky blue, sunny yellow, and green, with playful Fredoka display
typography paired with DM Sans for body copy. The homepage mark and palette
swatches echo the supplied logo reference. Google Fonts is used when available,
with system-font fallbacks.

The top-left home link uses the supplied transparent PNG at
`assets/sophia-bui-logo.png`.

Project pages use open, borderless header and footer dividers. The site scrollbar
is wider, with a white track and a single blue thumb.
